运行环境

GitHub Pages 版本为静态站。网页与 SDK 在浏览器内运行；fetch 端点由本站 Service Worker 处理，仅本站受控页面可用。curl / Python 调用需要另外部署仓库中的 Node HTTP 服务，不能直接向 Pages 发送动态 POST 请求。

接口参考
v1
POSTv1/chat/completions
返回最新一条 user 文本；按输出字符计费并返回 quantity 与用量明细。仅 TTC-5.2 Tomcat 可用；请求未接入模型返回 503 model_unavailable，不计费。不支持 stream: true。
GETv1/models
返回模型目录与本站接入状态；通过 available 字段区分是否可调用。
GETv1/balance
返回余额、成功请求数、累计计费字符和估算 token 用量。读取状态不计费。

          
部署独立 HTTP 服务
使用 Node.js 22+ 运行 npm start，默认端口为 8787。配置 HTTPS 后可对外提供 HTTP API。默认测试 Key 为 sk-relay-demo，可通过 API_KEY 修改。服务端与浏览器的账本互相独立；不要将私有密钥放进公开前端。
